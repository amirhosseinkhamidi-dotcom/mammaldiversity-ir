# پستانداران ایران — فهرست گونه‌ها

سایت استاتیک، بدون نیاز به npm/build. فایل‌های اصلی:

```
index.html                          صفحه‌ی اصلی — هیرو، آمار کلی، تنوع بر اساس راسته (بدون فهرست کامل گونه‌ها)
list.html                           فهرست کامل گونه‌ها — فیلتر راسته + جست‌وجو (آنچه قبلاً در index.html بود)
map.html                            نقشه‌ی تعاملی ۳۱ استان — اسکلت آماده، منتظر داده‌ی پراکنش استانی
species.html                        برگهٔ اختصاصی هر گونه (permalink) — قالب مشترک، با ?id=IRxxxx پر می‌شود
assets/style.css                    طراحی — الهام‌گرفته از Mammal Diversity Database، به فارسی/راست‌به‌چپ
assets/home.js                      صفحه‌ی اصلی: آمار، تنوع بر اساس راسته، گونه‌ی برجسته، جست‌وجوی هیرو
assets/script.js                    فهرست: فیلتر راسته + جست‌وجو + آمار خودکار (پشتیبانی از ?order=, ?q=, ?province=)
assets/species.js                   برگهٔ گونه: طبقه‌بندی، پراکنش جهانی، پیوند دائمی و استناد
assets/map.js                       نقشه: هاور/کلیک روی استان → تعداد گونه یا پیام «داده هنوز نیست»
assets/img/leopard-hero.jpg         عکس تله‌دوربین پلنگ ایرانی — هیرو صفحه‌ی اصلی (بهینه‌شده، ۳۳۶ کیلوبایت)
assets/img/iran-provinces.svg       نقشه‌ی SVG استان‌ها (geoBoundaries، ساده‌شده) — منبع build_province_map_svg.py
scripts/build_province_map_svg.py    یک‌بار اجرا می‌شود: geojson مرز استان‌ها → assets/img/iran-provinces.svg
data/species.json                   دیتاست — ۲۱۰ گونه، همیشه از اکسل زیر بازتولید می‌شود
data/دیتابیس_پستانداران_ایران.xlsx   منبع اصلی داده — اکسل کامل، قابل‌ویرایش — نگاه کنید به بخش پایین
scripts/species_fields.py           نگاشت مشترکِ فیلدهای JSON ↔ ستون‌های اکسل (هر دو اسکریپت زیر از همین استفاده می‌کنند)
scripts/build_database_template.py   می‌سازد: data/دیتابیس_پستانداران_ایران.xlsx از روی data/species.json فعلی
scripts/xlsx_to_json.py             می‌سازد: data/species.json از روی محتوای فعلی اکسل (منبع اصلی از این به بعد)
scripts/mdd_iran_to_json.py         فقط برای رفرش اولیه از CSV رسمی MDD — نگاه کنید به «به‌روزرسانی از MDD» پایین
README.md                           همین فایل
```

هر کارت در فهرست به `species.html?id=IRxxxx` لینک می‌شود — همان الگوی permalink که MDD برای هر taxon استفاده می‌کند (`mammaldiversity.org/taxon/…`). کارت‌های فهرست خلاصه‌اند، ولی برگهٔ هر گونه تقریباً **تمام ۵۲ ستون CSV رسمی MDD** را نشان می‌دهد: رده‌بندی کامل تا زیرجنس (نه فقط راسته/تیره)، نام اصلی هنگام توصیف + منبع + پیوند به سند اصلی، نمونه‌ی تیپ (voucher/kind/محل/مختصات)، فهرست کامل نام‌های مترادف و زیرگونه‌ها، پراکنش جهانی + قاره + قلمرو زیست‌جغرافیایی، و شناسه‌ی متقابل با CMW/MSW3 به‌همراه پیوند مستقیم به رکورد اصلی در mammaldiversity.org.

## اجرای محلی

مرورگرها اجازه نمی‌دهند فایل HTML را مستقیم دابل‌کلیک کنید و data/species.json را با fetch بخواند (محدودیت امنیتی file://). یک سرور محلی ساده کافی است:

```bash
cd site
python3 -m http.server 8000
```

بعد در مرورگر: `http://localhost:8000`

## منبع داده: اکسل کامل دیتابیس

`data/species.json` هرگز دستی ویرایش نمی‌شود. از این مرحله به بعد منبع اصلی خودِ **[`data/دیتابیس_پستانداران_ایران.xlsx`](data/دیتابیس_پستانداران_ایران.xlsx)** است (نه دیگر مستقیماً CSV رسمی MDD) — یک ردیف اکسل = یک گونه، با تقریباً همه‌ی فیلدهایی که در صفحه‌ی هر گونه نشان داده می‌شود. هر تغییری لازم شد — اصلاح یک نام، افزودن/حذف یک گونه، اضافه یا کم‌کردن یک فیلد — مستقیم در همین اکسل انجام می‌شود.

چهار شیت:

| شیت | کاربرد |
|---|---|
| `راهنما` | توضیح کامل هر شیت و هر ستون |
| `گونه‌ها` | **شیت اصلی** — یک ردیف به‌ازای هر گونه، ۵۵ ستون (رده‌بندی کامل تا زیرجنس، نام‌گذاری، نمونه‌ی تیپ، نام‌های مترادف، زیرگونه‌ها، پراکنش جهانی، وضعیت IUCN، شناسه‌ی متقابل CMW/MSW3، …) |
| `استان‌ها` | فهرست ۳۱ استان (فقط برای فهرست‌های کشویی) |
| `پراکنش_استانی` | یک ردیف به‌ازای هر رکورد پراکنش: شناسه‌گونه + استان + وضعیت حضور + **منبع** (الزامی) + سال + یادداشت |

نگاشتِ ستون‌های اکسل ↔ فیلدهای JSON در `scripts/species_fields.py` یک‌جا تعریف شده و هر دو جهت (ساخت اکسل، خواندن اکسل) از همان‌جا می‌آیند — اگر لازم شد فیلدی اضافه/کم شود، همان‌جا (`FIELDS = [...]`) ویرایش کنید، نه در دو جای مختلف.

**بعد از هر تغییر در اکسل:**

```bash
python3 scripts/xlsx_to_json.py data/دیتابیس_پستانداران_ایران.xlsx
```

این دستور `data/species.json` را **کامل از روی محتوای فعلی اکسل** بازمی‌سازد:
- ردیفی که پاک کرده باشید → آن گونه از سایت حذف می‌شود.
- ردیف تازه‌ای که اضافه کرده باشید (ستون «شناسه» را خالی بگذارید) → شناسه‌ی جدید (`IR0211`, ...) خودکار می‌گیرد و به سایت اضافه می‌شود.
- شیت «پراکنش_استانی» فهرست `provinces` هر گونه را می‌سازد؛ چهار حالت «وضعیت حضور»: حضور دارد / احتمالی-نیازمند تأیید / گزارش تاریخی / منقرض‌شده محلی.
- اعتبارسنجی مثل همیشه سخت‌گیرانه است — شناسه‌ی تکراری، نام علمی خالی، استان نامعتبر، یا ستون «منبع» خالی در شیت پراکنش، اسکریپت را متوقف می‌کند و شماره‌ی سطر واقعی اکسل را می‌گوید (طبق همان قولِ «هر رکورد دارای شناسه و منبع مجزاست» که در پابرگ سایت هست). ردیف‌های نمونه‌ی داخل تمپلیت (یادداشتشان با «نمونه —» شروع می‌شود) خودکار نادیده گرفته می‌شوند. کد IUCN نامعتبر خطا نمی‌دهد، فقط به `NE` (ارزیابی‌نشده) برمی‌گردد.

نیازمندی: `pip install openpyxl` (اگر نصب نیست).

بعد از این‌که پراکنش استانی واقعی وارد شد، بگویید تا فیلتر/نمایش استانی را به UI برگردانم (الان `assets/script.js`/`assets/species.js` بر پایه‌ی راسته و پراکنش جهانی‌اند، چون تا امروز داده‌ی استانی واقعی نبود).

### به‌روزرسانی از MDD (وقتی نسخه‌ی جدیدتری منتشر شد)

`scripts/xlsx_to_json.py` دیگر با MDD تماس نمی‌گیرد — اکسل منبع اصلی است. اگر بعداً خواستید از نسخه‌ی تازه‌ی MDD رفرش بگیرید (مثلاً v2.6)، کار دستی دو مرحله‌ای است چون باید ویرایش‌های دستی‌تان در اکسل با داده‌ی تازه‌ی MDD تطبیق داده شود — فعلاً این تطبیق خودکار نیست:

```bash
curl -L -o MDD.zip https://github.com/mammaldiversity/mammaldiversity.github.io/raw/refs/heads/master/assets/data/MDD.zip
unzip MDD.zip
python3 scripts/mdd_iran_to_json.py MDD/MDD_v2.x_NNNNspecies.csv data/species.json  # بازنویسی کامل از MDD
python3 scripts/build_database_template.py                                          # اکسل تازه از روی آن
```

توجه: این کار هر ویرایش دستی‌ای که در اکسل قبلی کرده بودید (نام فارسی، پراکنش استانی، اصلاحات دستی) را از بین می‌برد، چون از صفر از MDD می‌سازد. برای یک پروژه‌ی فعال، بهتر است پیش از رفرش از MDD یک نسخه از اکسل فعلی نگه دارید و ویرایش‌های مهم را دستی روی نسخه‌ی تازه پیاده کنید.

## استقرار (Deploy)

هیچ build step‌ای لازم نیست. وضعیت فعلی:

- **ریپو**: [github.com/amirhosseinkhamidi-dotcom/mammaldiversity-ir](https://github.com/amirhosseinkhamidi-dotcom/mammaldiversity-ir)
- **GitHub Pages**: فعال، شاخه‌ی `main`، ریشه‌ی ریپو.
- **دامنه‌ی سفارشی**: `mammaldiversity.ir` — DNS روی Cloudflare (حالت DNS only، نه Proxied) با ۴ رکورد A به آی‌پی‌های گیت‌هاب پیجز؛ فایل `CNAME` در ریشه‌ی ریپو ثبت شده. گواهی HTTPS در حال صدور خودکار توسط گیت‌هاب است.
- برای هر آپدیت: `python3 scripts/xlsx_to_json.py data/دیتابیس_پستانداران_ایران.xlsx && git add -A && git commit -m "..." && git push` — چند ثانیه بعد سایت خودکار به‌روز می‌شود.

## چیزهایی که عمداً هنوز نیست

- **پراکنش استانی** — اکسلِ جمع‌آوری‌اش آماده است (بخش بالا)، `map.html` هم آماده و منتظر داده است، ولی هنوز کسی اکسل رو پر نکرده. فیلتر فهرست فعلاً بر اساس راسته (Order) است.
- **نام فارسی کامل** — حدود ۱۵۷ گونه هنوز نام فارسی تأییدشده ندارند؛ ستون «نام فارسی»شان در اکسل خالی است، منتظر پر شدن.
- بخش سیتیزن‌ساینس (فاز ۲، طبق نقشه‌راه)

## تاریخچه‌ی تغییرات

- **طراحی**: پالت و اجزای بصری (رنگ تیل/سبزآبی، کارت‌های گردگوشه، تایپوگرافی سریف برای نام‌های علمی، نوار ناوبری بالا) از سایت اصلی [Mammal Diversity Database](https://www.mammaldiversity.org) اقتباس شده، با حفظ راست‌به‌چپ و فونت فارسی Vazirmatn.
- **صفحه‌ی اختصاصی گونه** اضافه شد (`species.html` + `assets/species.js`).
- **دیتاست واقعی** جایگزین ۶ گونه‌ی نمونه شد: ۲۱۰ گونه با حضور تأییدشده در ایران، مستقیم از CSV رسمی MDD (`scripts/mdd_iran_to_json.py`). فیلتر استانی موقتاً به فیلتر راسته تبدیل شد چون MDD داده‌ی سطح استان ندارد.
- **همه‌ی فیلدهای MDD** به دیتاست اضافه شد (نه فقط زیرمجموعه‌ی خلاصه‌شده): رده‌بندی کامل تا زیرجنس، نمونه‌ی تیپ، نام‌های مترادف، زیرگونه‌ها، منبع توصیف، و شناسه‌ی متقابل CMW/MSW3. برگهٔ هر گونه این‌ها را در پنل‌های جداگانه نشان می‌دهد (`data/species.json` از ۲۲۰ کیلوبایت به ~۱.۲ مگابایت رسید).
- **اکسل جمع‌آوری پراکنش استانی** ساخته شد (نسخه‌ی اول، بعداً جایگزین شد — پایین را بخوانید). فیلد «منبع» (الزامی) به مدل داده‌ی پراکنش استانی اضافه شد که قبلاً نبود.
- **اکسل کامل دیتابیس جایگزین نسخه‌ی قبلی شد**: چون درخواست شد «همه‌ی فیلدها قابل‌ویرایش باشد»، `scripts/build_database_template.py` جایگزین `build_province_template.py` شد — حالا شیت «گونه‌ها» تمام ۵۵ ستون هر گونه را دارد (نه فقط ۸ ستون مرجع)، و خودِ اکسل منبع اصلی داده است، نه CSV رسمی MDD. `scripts/xlsx_to_json.py` کامل بازنویسی شد تا کل `data/species.json` را از روی اکسل بسازد (اضافه/حذف/ویرایش هر ردیف پشتیبانی می‌شود، شناسه‌ی خودکار برای ردیف تازه). نگاشت ستون↔فیلد در `scripts/species_fields.py` یک‌جا تعریف شد تا دو اسکریپت از هم جدا نیفتند. روی این مسیر یک باگ حلقه‌ی بی‌نهایت (auto-vivify سلول در openpyxl هنگام خواندن ردیف‌های فراتر از انتهای واقعی) پیدا و رفع شد، و کل مسیر (ویرایش، افزودن، حذف، خطاهای اعتبارسنجی) با داده‌ی تستی بررسی شد.
- **صفحه‌ی اصلی بازطراحی شد**: `index.html` دیگر فهرست کامل ۲۱۰ گونه را نشان نمی‌دهد — فهرست کامل به `list.html` منتقل شد (همان تجربه‌ی قبلی: فیلتر راسته + جست‌وجو). صفحه‌ی اصلی حالا یک لندینگ واقعی است: هیرو با عکس تله‌دوربین پلنگ ایرانی (لینک‌شده به رکورد واقعی‌اش، `IR0046`)، نوار آمار بزرگ (گونه/راسته/تیره/بومی/در معرض خطر)، بخش «دربارهٔ این پایگاه»، و نمودار میله‌ای «تنوع بر اساس راسته» که هر ردیفش به `list.html?order=…` لینک می‌شود. جعبه‌ی جست‌وجوی هیرو هم به `list.html?q=…` می‌فرستد. برای همین دو پارامتر (`?order=`, `?q=`) پشتیبانی به `assets/script.js` اضافه شد. عکس اصلی (۵٫۴ مگابایت) با Pillow به ۳۳۶ کیلوبایت فشرده شد.
- **دیپلوی واقعی**: ریپو روی گیت‌هاب ساخته و push شد، GitHub Pages فعال شد، دامنه‌ی `mammaldiversity.ir` (که قبلاً ثبت شده بود) از طریق Cloudflare DNS به گیت‌هاب پیجز وصل شد.
- **نقشه‌ی تعاملی استان‌ها اضافه شد** (`map.html` + `assets/map.js` + `assets/img/iran-provinces.svg`): مرز واقعی ۳۱ استان از [geoBoundaries](https://www.geoboundaries.org) (© OpenStreetMap contributors, ODbL) گرفته شد و با یک اسکریپت یک‌بارمصرف (`scripts/build_province_map_svg.py`، شامل پیاده‌سازی خودِ Ramer–Douglas–Peucker برای ساده‌سازی مرزها) به SVG سبک (~۲۷ کیلوبایت) تبدیل شد. چون هنوز داده‌ی پراکنش استانی واقعی جمع نشده، نقشه فعلاً یک اسکلت است: کلیک روی هر استان یا به فهرست فیلترشده می‌رود (اگر داده داشته باشد) یا پیام «داده‌ی این استان هنوز جمع‌آوری نشده» را نشان می‌دهد. پارامتر `?province=` هم به `assets/script.js` اضافه شد تا وقتی داده وارد شد، این اتصال از قبل کار کند.
